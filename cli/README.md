# Create Disposabl app

Requires [Bun](https://bun.com) 1.4.4 or later.

```sh
bun create disposabl-app@latest my-app
cd my-app
bun run dev
```

Downloads the starter from [disposabl-dev/create-disposabl-app](https://github.com/disposabl-dev/create-disposabl-app), excludes the CLI and npm publishing workflow, and installs dependencies with Bun. Existing folders are never overwritten.
