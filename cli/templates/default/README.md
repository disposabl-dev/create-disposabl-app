# Disposabl app

Start the development server with [Bun](https://bun.com):

```sh
bun run dev
```

Open http://localhost:3000. Edit `index.ts` to build your app.

Run `bun run lint` for ESLint and `bun fmt` for formatting.
If you selected Docs, open http://localhost:3000/docs and edit `docs/index.html`.
