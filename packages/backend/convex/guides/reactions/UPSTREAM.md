# Convex Reactions

Vendored from [Convex Reactions](https://github.com/convex/reactions/tree/d7f500cb30bf09899eaa9a7aa5051389858e3816), Apache-2.0. The source is pinned because this component is unavailable from npm.

Disposabl uses explicit table names for database writes and adds an index and bounded cleanup mutation so account deletion removes the user's reactions even after a guide leaves the catalog. Host functions supply the authenticated user and a valid lesson ID.
