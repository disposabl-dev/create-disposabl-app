App functions live in `packages/backend/convex`. Shared authentication, storage, telemetry, and payment helpers live in `packages/disposabl-kit/server`.

Use the app's own development or isolated preview backend while coding and testing. Keep provider credentials on the backend; never expose secret keys through public client environment variables.

## Files and analytics

Files use Convex storage by default. Configuring all required Cloudflare R2 variables enables R2 for new uploads; existing file records retain their storage provider.

Analytics is optional and production-only. Local development and E2E runs must emit no telemetry. Keep captured metadata free of prompts, private content, credentials, and full URLs.
