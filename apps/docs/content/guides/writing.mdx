## Add a page

Create a Markdown or MDX file in `apps/docs/content` with a `title` in its frontmatter.
For example, `content/guides/setup.mdx` becomes `/docs/guides/setup`.

## Navigation

Fumapress builds the sidebar from the content directory. Add a `meta.json` file to control the page order.
